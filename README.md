# 🍕 Pizza Sales Analysis | SQL Server & Excel Dashboard

## 📌 Project Overview
This project analyzes pizza sales data using **SQL Server and Microsoft Excel** to identify key business insights, sales trends, and product performance. SQL queries were used to calculate key performance indicators (KPIs) and analyze sales by time, pizza category, size, and product popularity. An interactive Excel dashboard was created to visualize the results and support data-driven decision-making.

## 🎯 Project Objectives
- Analyze overall sales performance using key business KPIs.
- Identify daily and hourly order trends.
- Understand the contribution of different pizza categories and sizes to total sales.
- Identify the best-selling and lowest-selling pizzas based on quantity sold.
- Present insights through an Excel dashboard for easier interpretation.

## 🛠️ Tools & Technologies
- **SQL Server:** Data analysis, aggregations, KPI calculations, and trend analysis.
- **Microsoft Excel:** Dashboard creation and data visualization.

## 📊 Key Performance Indicators (KPIs)
- **Total Revenue:** Total sales generated from pizza orders.
- **Average Order Value:** Average revenue generated per order.
- **Total Pizzas Sold:** Total quantity of pizzas sold.
- **Total Orders:** Total number of unique orders.
- **Average Pizzas Per Order:** Average number of pizzas sold per order.

## 📈 Analysis Performed
1. **Daily Order Trends:** Analyzed the number of orders by day of the week.
2. **Hourly Order Trends:** Examined order distribution across different hours of the day.
3. **Sales by Pizza Category:** Calculated revenue and percentage contribution for each category.
4. **Sales by Pizza Size:** Evaluated revenue and percentage contribution by pizza size.
5. **Pizzas Sold by Category:** Compared the total quantity sold across categories.
6. **Top 5 Best-Selling Pizzas:** Identified the five pizzas with the highest sales quantities.
7. **Bottom 5 Lowest-Selling Pizzas:** Identified the five pizzas with the lowest sales quantities.

## 💡 Skills Demonstrated
- SQL querying and data aggregation
- Aggregate functions: `SUM()`, `COUNT()`, and `AVG()` concepts
- Grouping and filtering with `GROUP BY` and `HAVING`
- Date and time functions using `DATENAME()` and `DATEPART()`
- Subqueries and percentage calculations
- KPI development and business performance analysis
- Excel dashboard creation and data visualization

## 📂 Project Files
- `pizza_sales_queries.sql` – SQL queries used for KPI calculations and sales analysis.
- `pizza_sales_dashboard.xlsx` – Excel dashboard presenting sales KPIs, trends, and product performance.

## 🚀 Key Takeaway
This project demonstrates the application of SQL Server and Excel to transform raw pizza sales data into meaningful business insights, helping stakeholders understand sales performance, customer ordering patterns, and product-level trends.
